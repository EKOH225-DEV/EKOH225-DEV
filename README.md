## Projet phare : SAFE-SECURITE

Logiciel de gestion des agents pour une entreprise de gardiennage d'Abidjan (client réel, en cours de livraison).
Le code appartient au client et reste privé.

- Attestations de formation en PDF générées automatiquement, numérotation sans trou ni doublon
- QR code sur chaque attestation et page publique de vérification anti-fraude
- Connexion sécurisée (argon2id, limitation des tentatives), gestion des agents
- Plusieurs centaines de tests unitaires et 32 tests dans un vrai navigateur (Playwright)

`Next.js` `TypeScript` `PostgreSQL` `Prisma` `Playwright` `Claude Code`
